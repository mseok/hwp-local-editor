# Table captions

Part of `hwp-agent-edit`; read after the per-document steps in `SKILL.md`.

To create or enter a table caption, find a cell in the requested table, close Find and right-click that cell. Choose **캡션 넣기(A)** from its context menu. A missing caption is created; an existing caption is opened at its end. Esc can first select the whole table; its context menu uses the same full path. The Input menu's **캡션 넣기** is a picture command, so do not use it for tables. Ordinary and two-/three-level table caption creation, typing, deletion, undo/redo, journal recovery and saved reopening have been checked in both formats. After reloading, select the table and enter its caption again before typing. Confirm the actual saved caption through the rendered page, text panel or a path-specific read. The text panel and saved text fingerprint include table-caption paragraphs once after body/table text. In short panels, the cell context menu stays within the editor viewport and scrolls to expose lower commands. Caption creation and entry with **현재 문서 텍스트** left open have been checked at a 720-pixel page height in both formats. Edited enclosing host text remains inside its cell and separate from its nested table in these checks. Captions can still overlap neighbouring text when the source table is wider than its containing cell; inspect their bounds rather than inferring layout fidelity from a successful save. Caption Find, single replacement and all replacement have also been checked for ordinary and two-/three-level captions in both formats, including undo, recovery and saved reopening. Caption hits retain a full path even at depth one. For caption formatting, select the intended text using Find and close Find before applying **굵게**, **글자 크기(pt)** or paragraph alignment. Caption text-range/caret character and paragraph formatting, Enter splitting, Home/Backspace merging, undo/redo, journal recovery and saved reopening have been checked for new/existing ordinary and two-/three-level captions in both formats. Home/End retain the full path and selected visual line at wrapped boundaries. Caption numbering is a display projection, so it does not shift editable text offsets. Paragraph alignment for selected ordinary and two-/three-level cell blocks is also verified; the block route is described below. Save and reopen the result, then inspect the actual caption and surrounding text; these checks do not establish native Hancom fidelity.

To place a caption beside a table, find/select the table cell and open **표 → 표/셀 속성 → 여백/캡션**. Use a named button such as **캡션 왼쪽 아래** or **캡션 오른쪽 가운데**, enter **캡션 너비(mm)** and **캡션 간격(mm)**, then click **확인**. The active button exposes its pressed state. **캡션 위**, **캡션 아래** and **캡션 없음** are also named; top/bottom placement disables the side-width input. All six side placements, undo/redo, journal recovery and disk-result reopening have been checked for ordinary and two-/three-level tables in both formats. Side width and gap reserve inline space without resizing the table. Inspect nearby host text and enclosing bounds; the tested fixtures have room for the caption. After an engine update, keep any incompatible old recovery journal and use the task list's **저장 결과 다시 열기** link to begin from the saved file. Reloading an old draft URL does not reopen the disk result.
