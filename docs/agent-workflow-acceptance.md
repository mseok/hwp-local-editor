# Full agent-workflow acceptance

The goal remains: a user supplies several HWP/HWPX files and edit instructions; Codex or Claude edits through browser computer use, checks saved editable results and returns them with source structure preserved, without routine foreground/native Hancom interaction. A passing subset does not complete this goal.

This is the requirement checklist as of 2026-10-10. Detailed evidence and earlier checkpoints are in `verification.md`. Local reports and real-browser artifacts are deliberately ignored by Git because document-derived evidence may be private.

The current build passes 174 checks across nine suites. Nested movement and cutting use full paths. Browser clipboard events and edit-menu cuts remove the selected inner table and preserve its enclosing content. Recovered paste retains table geometry, cell properties and text across repeated reloads without a full-file export during typing. Logical undo handles remain valid when a new journal continues a replayed prefix. Movement still preserves live/saved enclosing geometry and preceding text growth still advances tables. This does not close the outstanding boundaries above. Continue with table transpose/caption routes, special-object editing/preservation and exact-source native fidelity. Establish failing reproducers before changing those routes; do not disable requested functionality or redefine the goal to the already passing cases.
